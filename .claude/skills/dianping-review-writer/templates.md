# 大众点评评价模板

## 火锅/串串

**关键词：** 锅底、涮菜新鲜度、小料台、排队情况

**结构：**
- 开头：被朋友安利/路过发现的
- 锅底：辣度、香味、是否越煮越咸
- 推荐菜：毛肚、鹅肠、嫩牛肉等具体菜品口感
- 小料台：种类多不多、有没有特色蘸料
- 价格：人均、是否有套餐

**示例关键词：** 「牛油锅底」越煮越香 「贡菜」脆脆的口感 「冰粉」解辣神器

## 烤肉/烧肉

**关键词：** 肉质、炭火/电烤、油烟处理、蘸料

**结构：**
- 开头：想吃肉了/朋友聚餐
- 肉类点评：具体部位口感（牛舌、横膈膜、五花肉）
- 烤制方式：炭火香还是电烤
- 油烟处理：衣服会不会有味道
- 配菜：生菜新鲜度、泡菜种类
- 价格：自助还是单点，性价比

## 自助/放题

**关键词：** 补货速度、品类丰富度、限时、有没有隐形消费

**结构：**
- 开头：和朋友来吃的自助
- 品类：海鲜、肉类、甜品各区的丰富程度
- 补货：热门菜品会不会断供
- 限时：点餐时间限制、用餐时长
- 隐藏消费：锅底另收费、押金等
- 性价比：对比同价位其他自助

## 江浙菜/本帮菜

**关键词：** 浓油赤酱、甜口、老字号、功夫菜

**结构：**
- 开头：想吃本帮菜/家庭聚餐
- 环境：是否有老上海风情
- 招牌菜：红烧肉、糖醋排骨、响油鳝丝等
- 口味：甜度是否适中、酱汁是否到位
- 价格：人均、适合什么场合

## 川菜/湘菜

**关键词：** 辣度、麻度、下饭、烟火气

**结构：**
- 开头：很久没吃辣/朋友爱吃辣
- 辣度体验：辣得舒服还是纯辣不香
- 推荐菜：水煮鱼、辣子鸡、小炒肉等
- 米饭：是不是下饭神器
- 价格：人均、份量

## 日料/寿喜烧

**关键词：** 新鲜度、摆盘、服务、性价比

**结构：**
- 开头：想吃不那么油腻的
- 刺身：厚度、新鲜度、种类
- 寿喜锅：汤底甜咸比、牛肉品质
- 服务：是否帮忙涮肉
- 环境：日式装修、安静程度

## 小吃/大排档

**关键词：** 烟火气、性价比、分量、排队

**结构：**
- 开头：被种草很久/路过发现
- 位置：好不好找、要不要排队
- 招牌：具体是什么、口感如何
- 价格：单价、人均
- 氛围：大排档的热闹感

## 咖啡/甜品

**关键词：** 口味层次、甜度、颜值、适合拍照

**结构：**
- 开头：下午茶/路过歇脚
- 环境：装修风格、是否安静适合办公
- 出品：具体单品口感和层次
- 甜度：会不会太甜
- 价格：对比星巴克/同类店

## 通用万能结构

如果用户提供的信息很少，用这个结构：

```
[怎么发现的这家店 - 1句]
[点了什么 + 最好吃的一道详细写 - 3句]
[环境和服务的感受 - 2句]
[人均价格和性价比感觉 - 1句]
[会不会再来 - 1句]
```
