# 大众点评评价写作

## Overview

帮助用户写出通过审核、计入橙V、不被折叠的大众点评评价。核心原则：**真实感 > 文采，细节 > 概括**。

## Quick Reference

| 项目 | 要求 |
|------|------|
| 橙V开通 | 4条100字以上打星评价，30天内完成 |
| 橙V维持 | 每月4条100字评价（商户评价，笔记不算） |
| 字数底线 | ≥100字（橙V门槛），建议150-300字 |
| 图片建议 | 3-6张实拍图最佳 |
| 不计入项 | 电影、外卖、酒旅点评 |
| 评分结构 | 口味/环境/服务 三项分别打分 |

## Anti-Fraud Rules (风控规避)

写评价时必须提醒用户：

1. **不要秒进秒写** — 先在店铺页浏览至少30秒，看看其他评价
2. **不要集中发布** — 同一天不超过2-3条，间隔至少1小时
3. **不要连着店内WiFi写** — 会被判定为商家自刷
4. **不要复制粘贴** — 每条评价内容要有区分度
5. **不要秒删重发** — 删除评价会导致橙V撤回

## Review Structure

```
[场景引入] 1-2句 — 怎么去的、和谁、为什么选这家
[环境] 1-2句 — 装修风格、氛围、卫生
[菜品详评] 3-5句 — 具体菜名+口感+对比，这是核心
[价格] 1句 — 人均、性价比
[服务/其他] 1句 — 上菜速度、服务员态度
[结尾] 1句 — 是否推荐、是否会再来
```

## 评分策略

| 总体感受 | 口味 | 环境 | 服务 |
|----------|------|------|------|
| 非常好 | 5 | 4-5 | 4-5 |
| 好 | 4 | 4 | 3-4 |
| 一般 | 3 | 3 | 3 |

- 不要全部5星 — 太假，容易被判定刷分
- 口味是最重要的维度，通常打最高分
- 环境和服务可以挑一个小缺点降低0.5-1星

## Workflow

与用户协作流程：

1. 确认店铺名和类型
2. 询问关键体验信息（吃了什么菜、和谁去的、花了多少钱）
3. 如果信息不足，引导用户补充
4. 生成评价文案
5. 提醒风控注意事项
6. 建议评分

## Common Mistakes

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 全5星好评 | 判定刷分 | 有区分度地打分 |
| 评价太短（<100字） | 不计橙V | 至少100字 |
| 只写"好吃""不错" | 被折叠 | 具体描述口感 |
| 同一天写5-6条 | 全部降权 | 每天2-3条，隔1小时 |
| 没有图片 | 权重低 | 至少3张实拍 |
| 用笔记代替评价 | 不计橙V | 必须打星才是评价 |
